# Organisation par projets

Ce dépôt contient le site Gang of Bordeaux (`index.html` : simulateur de budget traiteur, 250 convives max).
Le dossier `projets/` regroupe le contexte de chaque activité. Avant de travailler, lis le `README.md` du projet concerné.

| Projet | Dossier | Étiquette des sessions |
|---|---|---|
| IA fiscal | `projets/ia-fiscal/` (code : dépôt `ia-fiscale`) | `projet:ia-fiscal` |
| Gang of Bordeaux | `projets/gang-of-bordeaux/` | `projet:gang-of-bordeaux` |
| SCI des barrettes | `projets/sci-des-barrettes/` | `projet:sci-des-barrettes` |
| Architecture conciergerie | `projets/architecture-conciergerie/` | `projet:architecture-conciergerie` |
| Badminton TOU.S | `projets/badminton-tous/` | `projet:badminton-tous` |

Règle : un document ou un fichier appartient à un seul projet. Range-le dans son dossier.
